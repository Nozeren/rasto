# Rasto for thumbdeck

Adds **Rasto** to thumbdeck's Plugins pane (`Ctrl+p`). Selecting it opens Rasto, or brings it to the front when it is
already running (during a recording: its HUD). The pane shows *running* next to the name while Rasto is open; in the
view, `l` or **Open Rasto** does the same again.

Install: thumbdeck **Settings** (`,`) **› Plugins › Add a plugin › Use a folder…** → this `thumbdeck` folder.

Needs Rasto installed in Applications (macOS, `open -a Rasto`); on Linux it runs `rasto`.
